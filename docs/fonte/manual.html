Capítulo 1

Novidades da interface

Esta rodada mexe só na interface. A API, o formato JSON e o banco são os mesmos da 1.1.0, então quadros exportados antes abrem sem conversão.

  • Mesa de obra. O quadro fica sobre papel milimetrado; cada coluna é uma raia com cantos arredondados e as tarefas são fichas brancas com o título em Literata. O logo virou um prumo de pedreiro em branco sobre um quadrado preto.
  • Tipografia do Lume. Literata nos títulos e nas tarefas, Public Sans na interface e IBM Plex Mono nos números (contagens, limite WIP, dias na coluna), no lugar da Schibsted Grotesk e da Source Serif 4.
  • Adição rápida. Ao criar uma tarefa, @ana #bug !alta >sexta já preenche responsável, etiqueta, prioridade e prazo, com uma prévia antes de salvar (seção 4.4).
  • Filtros rápidos. Os cinco seletores viraram botões de um clique, cada um com a contagem: Minhas tarefas, Atrasadas, Bloqueadas e Paradas há 5 dias. Os filtros completos ficam em Mais filtros (seção 4.8).
  • Tarefas paradas. O card mostra há quantos dias está na mesma coluna quando passa de 5; acima de 10 o selo fica vermelho.
  • Ações rápidas no card. Passe o mouse para Assumir a tarefa ou movê-la para a próxima coluna sem abrir a janela.
  • Colunas recolhidas. A seta no topo encolhe a coluna numa faixa vertical; ela continua recebendo tarefas arrastadas.
  • Vista Lista. Todas as tarefas numa tabela que ordena por título, status, responsável, prioridade, prazo ou dias na coluna (seção 5.1).
  • Ir para (Ctrl+K). Uma caixa que encontra qualquer tarefa, quadro, vista ou ação pelo nome (seção 4.9).
  • Atalhos novos. M mostra só as suas tarefas, 1 a 5 trocam de vista e o rodapé tem o link Atalhos.
  • Capturas de tela e os dois manuais refeitos. O HTML dos PDFs agora fica no repositório, em docs/fonte/.
Capítulo 2

Visão geral

O Prumo é um gerenciador de tarefas no estilo Kanban. Toda a lógica do quadro fica em módulos JavaScript na pasta web/js e roda direto no navegador, sem etapa de build.

Mover tarefas, limites WIP, dependências, automações, desfazer e refazer, métricas, filtros, adição rápida, importação e exportação são funções puras testadas no Node. O servidor em Django é opcional. Sem ele, o Prumo guarda tudo no localStorage do navegador. Com ele, os quadros vão para o PostgreSQL, cada pessoa entra com a própria conta, os papéis passam a valer e as alterações chegam por WebSocket a quem estiver com o mesmo quadro aberto.

Identidade visual

O nome vem do prumo de pedreiro, o peso na ponta de um fio que mostra o que está alinhado. A interface é uma mesa de obra: papel milimetrado sob o quadro, tinta grafite, o azul da linha de giz para ações e foco e o latão para destaques. Capítulo 3

Instalar e rodar

Com Docker, um script sobe o banco e o servidor e abre o navegador. Sem Docker, dá para usar só a interface ou o Django direto.

Com Docker

  1. Baixe o projeto com git clone https://github.com/Violet-pixel/Interactive-Kanban-Board.git ou pelo ZIP do botão Code no GitHub.
  2. No Windows, dê dois cliques em iniciar.cmd. No Linux ou no macOS, rode ./iniciar.sh.
  3. Na primeira vez, o script copia .env.example para .env e sorteia a senha do banco e a chave do Django.
  4. O Docker sobe dois contêineres: postgres (banco) e web (Django e Daphne). O web aplica as migrações e cria a demonstração se o banco estiver vazio.
  5. Quando /api/v1/saude responder, o navegador abre em http://localhost:8080.
docker compose ps                # estado dos contêineres
docker compose logs -f web       # acompanhar o servidor
docker compose down              # parar (os dados ficam no volume)
docker compose down -v           # parar e apagar banco e anexos

Contas de demonstração

PapelE-mailO que pode fazer
Administradoradmin@prumo.devTudo, incluindo membros e exclusão do quadro
Gerentegerente@prumo.devTarefas, colunas, etiquetas, limites WIP e automações
Membromembro@prumo.devCriar, editar, mover e comentar tarefas
Visualizadorleitura@prumo.devSó consultar

Todas usam a senha Prumo@2026. Os nomes são fictícios e os e-mails usam o domínio de exemplo prumo.dev.

Modo local sem servidor

Rode npm run servir na pasta do projeto e abra http://localhost:5173. O Prumo abre com o quadro de exemplo e grava cada alteração no navegador. Os dados ficam só naquele navegador e naquele computador. Para levá-los a outro lugar, use Menu, Exportar e importar.

Papéis no modo localO papel escolhido em Conta e sincronização muda só o que a tela mostra. A restrição só é aplicada quando o quadro está no servidor.

Servidor sem Docker

python -m venv .venv
.venv\Scripts\activate           # Windows (Linux e macOS: source .venv/bin/activate)
pip install -r requirements.txt
python manage.py migrate
python manage.py seed            # contas e quadro de demonstração
daphne -p 8000 prumo.asgi:application

Sem variáveis de ambiente, o Django usa SQLite (prumo.sqlite3). Para usar PostgreSQL, defina PRUMO_DB_ENGINE=postgresql e as variáveis PRUMO_DB_* antes do migrate.

Capítulo 4

Usar o quadro

Tudo o que você muda é salvo na hora. Cada passo pode ser desfeito com Ctrl+Z.

4.1 A tela principal

ÁreaO que tem
Barra superiorLogo, nome e descrição do quadro, abas Quadro, Lista, Calendário, Painel e Histórico, busca (/), Ir para (Ctrl+K), desfazer, refazer, notificações, tema e menu
LateralQuadros ativos com o total de tarefas, botão de novo quadro, arquivados, quem está online e a sua conta

4.2 Quadros e modelos

  1. Clique em + ao lado de Quadros.
  2. Dê um nome, escolha o modelo e a cor e clique em Criar quadro.
ModeloColunas criadas, em ordem
KanbanBacklog, To Do, In Progress (WIP 3), Review (WIP 2), Done
ScrumProduct Backlog, Sprint Backlog, Em andamento (WIP 4), Teste (WIP 2), Pronto
DesenvolvimentoIdeias, Especificação, Desenvolvimento, Code Review, QA, Produção
EstudosPara estudar, Estudando (WIP 2), Revisar, Aprendido
Gestão de projetosPlanejamento, Execução (WIP 5), Aprovação (WIP 3), Entregue

Em Configurar você renomeia o quadro, muda a cor, edita as etiquetas e decide se dependências bloqueiam ou só avisam. Ali também ficam Duplicar, Arquivar e Excluir quadro. Quadros arquivados saem da lista principal e aparecem em Mostrar arquivados. Duplicar copia colunas, tarefas, etiquetas e automações e começa um histórico novo.

4.3 Colunas, limites WIP e colunas recolhidas

Clique em Nova coluna no fim do quadro. Para mudar a ordem, arraste o topo da coluna. O botão de três pontos abre o nome, o tipo da etapa e o limite WIP.

TipoEfeito
EsperaA tarefa ainda não começou. Dependências pendentes não impedem a entrada.
Em andamentoA primeira entrada marca o início do cycle time.
ConcluídoMarca a data de conclusão. Sair dela reabre a tarefa.

Com limite WIP, o topo da coluna mostra um nível de bolha com uma régua embaixo e o contador no formato tarefas/limite. A régua tem uma marca numerada por vaga, e a bolha anda até a marca do total de tarefas. Quando falta uma vaga, a bolha ganha contorno latão. Quando a coluna lota, o tubo fica vermelho e a próxima tarefa é recusada com uma mensagem.

1 de 3: livreA bolha anda até a marca do total.
2 de 3: falta uma vagaA bolha ganha contorno latão.
3 de 3: cheiaO tubo fica vermelho.

Enquanto você arrasta uma tarefa, a coluna de destino fica azulada; se estiver cheia, avermelhada. Limite 0 significa sem limite; nesse caso a coluna mostra Sem limite WIP. Excluir uma coluna leva as tarefas dela para a coluna anterior.

Recolher. A seta à esquerda do nome encolhe a coluna numa faixa vertical com o nome e a contagem. Clique na faixa para abrir de novo. Uma coluna recolhida continua recebendo tarefas arrastadas (elas vão para o fim). A escolha fica salva no navegador, por quadro.

4.4 Tarefas e adição rápida

Clique em Adicionar tarefa no pé da coluna (ou tecle N), escreva o título e tecle Enter. O campo continua aberto para a próxima tarefa. Marcações no título preenchem os campos na hora, e uma prévia mostra o que foi entendido antes de salvar:

MarcaçãoPreencheExemplos
@nomeResponsável, pelo começo do nome de quem já está no quadro@ana, @bruno_lima
#etiquetaEtiqueta existente; use hífen no lugar do espaço#bug, #nova-funcao
!prioridadeUrgente, alta, média ou baixa (ou só a inicial)!alta, !u
>prazoHoje, amanhã, dia da semana, data ou daqui a N dias>sexta, >15/11, >+3

Marcações que não casam com nada aparecem na prévia como aviso e ficam fora do título. Automações da coluna rodam depois e podem completar ou trocar campos.

Clique no card para abrir os detalhes.

CampoUso
Título e descriçãoSalvos quando o campo perde o foco
StatusMove a tarefa para outra coluna, respeitando WIP e dependências
ResponsávelTexto livre, com sugestões dos membros e de quem já tem tarefas
PrioridadeUrgente, alta, média ou baixa. No card, uma barra à esquerda: vermelha para urgente, latão para alta
Início e prazoO prazo gera os selos Hoje e Atrasada, alimenta o calendário e as notificações
EtiquetasClique para ligar ou desligar. Gerentes criam etiquetas novas ali mesmo

No pé da janela ficam Duplicar e Excluir. Excluir pede confirmação e pode ser desfeito com Ctrl+Z.

4.5 Arrastar, soltar e ações rápidas

O Prumo usa só a API nativa do HTML5 (dragstart, dragover, drop, dragend). Enquanto você arrasta, uma linha azul marca onde a tarefa vai cair. Ao soltar, a função moverCard confere o limite WIP e as dependências, registra a movimentação, recalcula a ordem e roda as automações. Com filtros ativos, o arrastar continua funcionando.

Com a tarefa em focoAção
Alt + → / ←Próxima coluna / coluna anterior
Alt + ↑ / ↓Sobe ou desce na coluna
EnterAbre a tarefa

Ações rápidas. Ao passar o mouse (ou com a tarefa em foco), o rodapé do card mostra Assumir, que põe você como responsável, e um botão com o nome da próxima coluna, que move a tarefa para lá respeitando WIP e dependências. No celular os botões ficam sempre visíveis.

Tarefas paradas. Quando uma tarefa não concluída está há 5 dias ou mais na mesma coluna, o card ganha o selo com a ampulheta e o número de dias; a partir de 10 dias o selo fica vermelho. A contagem usa as movimentações da tarefa (ou a data de criação, se ela nunca saiu da coluna).

4.6 Subtarefas, anexos e comentários

Subtarefas
Escreva e clique em Adicionar. Marque a caixa para concluir. O card mostra feitas e total, com uma barra de progresso.
Anexos
Clique em Anexar arquivo ou arraste arquivos para dentro da janela. Imagens ganham miniatura. No modo local o limite é 2 MB por arquivo; com o servidor, o arquivo vai para o disco e o limite é PRUMO_MAX_ANEXO_MB.
Comentários
Escreva e clique em Comentar. Use @Nome para mencionar alguém; a pessoa recebe uma notificação.

4.7 Dependências

  1. Abra a tarefa que precisa esperar outra.
  2. Em Dependências, escolha a tarefa e clique em Vincular.
  3. Enquanto a dependência não estiver numa coluna do tipo Concluído, o card leva a faixa zebrada no topo e o selo Bloqueada.

Com Impedir que tarefas avancem ligado (o padrão), mover a tarefa para uma coluna que não seja de espera é recusado. Desligado, o Prumo só avisa. Vínculos que formariam um ciclo são recusados. Ao excluir uma tarefa, os vínculos que apontavam para ela somem.

4.8 Busca e filtros rápidos

A busca (tecla /) procura em título, descrição, responsável e subtarefas, sem diferenciar acentos nem maiúsculas. Com vários termos, todos precisam aparecer. Os filtros se somam à busca e valem no quadro, na lista e no calendário.

Filtro rápidoMostra
Minhas tarefas (M)As tarefas em que você é responsável
AtrasadasPrazo anterior a hoje e tarefa não concluída
BloqueadasTarefas com dependências ainda não concluídas
Paradas há 5 diasTarefas não concluídas há 5 dias ou mais na mesma coluna
Mais filtrosResponsável (ou sem responsável), etiqueta, prioridade, prazo (atrasadas, hoje, próximos 7 dias, sem prazo) e status

Cada botão mostra quantas tarefas ele traria e fica escuro quando está ligado. Um segundo clique desliga; Limpar desliga todos. Com filtros ativos, o contador das colunas mostra “1 de 2”.

4.9 Ir para (Ctrl+K) e atalhos

Ctrl+K (ou o botão Ir para, no topo) abre uma caixa que encontra pelo nome qualquer tarefa do quadro, outro quadro, uma vista ou uma ação (nova tarefa, minhas tarefas, novo quadro, exportar, tema, atalhos). As setas escolhem, Enter abre e Esc fecha.

NNova tarefa na primeira coluna

Capítulo 5

Vistas

O mesmo quadro visto de cinco jeitos. As abas ficam no topo e as teclas 1 a 5 trocam de uma para outra.

5.1 Lista

Uma linha por tarefa, com título e etiquetas, status, responsável, prioridade, prazo e há quantos dias está na coluna. Clique no título de uma coluna da tabela para ordenar; de novo para inverter. Clique numa linha (ou Enter com ela em foco) para abrir a tarefa. Os filtros e a busca valem aqui.

5.2 Calendário

Mostra as tarefas com prazo no mês, com a semana começando na segunda-feira. As setas trocam o mês e Hoje volta ao mês atual. Tarefas atrasadas ficam em vermelho e aparecem também numa lista abaixo da grade. Clique numa tarefa para abri-la.

5.3 Painel e métricas

IndicadorCálculo
Concluídas e pendentesTarefas em coluna do tipo Concluído, e todas as outras
AtrasadasPrazo anterior a hoje e tarefa não concluída
Lead timeDa criação até a conclusão (mediana e média, em dias)
Cycle timeDa primeira entrada numa coluna em andamento até a conclusão
ThroughputMédia de tarefas concluídas por semana nas últimas 4 semanas
Fluxo cumulativoQuantas tarefas estavam em cada coluna no fim de cada um dos últimos 14 dias, reconstruído pelas movimentações

Os gráficos são SVG gerados em web/js/ui/vistas.js, sem bibliotecas. As fórmulas ficam em web/js/metricas.js; a idade na coluna, em web/js/filtros.js.

5.4 Histórico, desfazer e refazer

A aba Histórico lista as últimas 500 alterações do quadro com autor, ação e horário. A busca da barra filtra o histórico. Cada tarefa também mostra o próprio histórico. Desfazer e refazer guardam até 100 passos por aba do navegador; dá para desfazer qualquer operação, inclusive exclusões e importações. Quando outra pessoa altera o quadro no servidor, a pilha é zerada, para você não voltar por cima do trabalho dela.

Capítulo 6

Equipe e automação

Regras que fazem o trabalho repetitivo, avisos de prazo e menção, papéis por quadro e sincronização em tempo real.

6.1 Automações

Uma regra tem um gatilho e uma ação. O gatilho é a tarefa entrar numa coluna ou ser criada nela; a coluna pode ser qualquer uma.

AçãoValor
Definir responsávelNome da pessoa
Definir prioridadeUrgente, alta, média ou baixa
Adicionar etiquetaUma etiqueta do quadro
Mover para a colunaA coluna de destino (respeita WIP)
Marcar todas as subtarefasNão tem valor
Definir prazo em diasDias a partir de hoje

Uma regra que move a tarefa pode disparar outras, até 3 níveis. Cada aplicação aparece no histórico com o autor Automação. O interruptor pausa a regra sem apagá-la.

6.2 Notificações

O sino mostra quantas notificações não lidas existem. O Prumo verifica a cada minuto e a cada alteração: suas tarefas que vencem hoje ou estão atrasadas, comentários que mencionam você e atribuições ou alterações feitas por outras pessoas nas suas tarefas. Clique em Receber alertas do navegador para ver as notificações do sistema com a aba em segundo plano.

6.3 Contas, papéis e tempo real

PapelPode
AdministradorTudo: membros e papéis, excluir o quadro, colunas, etiquetas, automações, tarefas
GerenteColunas, limites WIP, etiquetas, automações, configurações e tarefas
MembroCriar, editar, mover, comentar e anexar em tarefas
VisualizadorSó consultar (sem ações rápidas nem adição de tarefas)
  1. Clique no seu nome no canto inferior esquerdo.
  2. Em Entrar no servidor, use e-mail e senha. Na demonstração: admin@prumo.dev e Prumo@2026.
  3. Os quadros do servidor aparecem com um ponto na lateral. Para enviar um quadro local, use Enviar para o servidor na mesma janela.
  4. Abra o mesmo quadro em outro navegador, com outra conta: cada movimentação aparece na hora e a lateral mostra quem está online.

Para dar acesso, o administrador abre Membros, informa o e-mail de uma conta existente e escolhe o papel. Contas novas são criadas com python manage.py criarusuario --email ... --nome "..."; com --admin, a conta vê todos os quadros.

ConflitosQuando duas pessoas salvam ao mesmo tempo, a segunda recebe a versão mais recente com o aviso “Outra pessoa alterou o quadro ao mesmo tempo”. Nada é sobrescrito sem ser visto.

6.4 Exportar e importar

OpçãoResultado
Este quadro em JSONArquivo completo e reimportável, com colunas, tarefas, etiquetas, automações e histórico
Tarefas em CSVUma linha por tarefa, UTF-8 com BOM, separador vírgula
Todos os quadros em JSONBackup de tudo o que está no navegador

Colunas do CSV, nesta ordem: id, quadro, coluna, titulo, descricao, responsavel, prioridade, etiquetas, prazo, subtarefas_feitas, subtarefas_total, dependencias, criado_em, iniciado_em, concluido_em. Etiquetas e dependências são separadas por |. Na importação, só titulo é obrigatório; o separador ponto e vírgula também é aceito, e colunas ou etiquetas que não existirem são criadas.

Base: /api/v1. Envie Authorization: Bearer <token> em todas as rotas, exceto /, /saude e /auth/entrar. Erros vêm como {"mensagem": "..."}.

Capítulo 8

Solução de problemas

Os sintomas mais comuns e o que fazer.

SintomaCausa e solução
Docker não encontradoInstale o Docker Desktop e abra-o antes de rodar o iniciar.cmd.
A porta 8080 já está em usoTroque PRUMO_PORT no .env e rode de novo.
Não aparece Entrar no servidorA interface está sendo servida sem o Django (por exemplo, com npm run servir). Use a porta do Docker.
E-mail ou senha incorretos na demonstraçãoO seed só roda em banco vazio. Rode docker compose exec web python manage.py seed.
A tarefa não entra na colunaA coluna está no limite WIP ou há dependências pendentes; a mensagem diz qual dos dois.
A adição rápida não reconheceu @nome ou #etiquetaA pessoa precisa ser membro ou já ter tarefas no quadro, e a etiqueta precisa existir. Use hífen no lugar do espaço.
Uma coluna sumiuEla está recolhida: procure a faixa vertical com o nome e clique nela.
Seu papel não permite essa alteraçãoMembros não mudam colunas, etiquetas nem automações. Peça ao administrador para mudar seu papel em Membros.
Anexo recusado no modo localO arquivo passa de 2 MB. Use o servidor.
Os dados sumiram do navegadorOs dados do site foram limpos ou a janela era anônima. Faça backup com Todos os quadros em JSON.
O tempo real não atualiza atrás de um proxyLibere o upgrade de WebSocket para /ws/ e defina PRUMO_ALLOWED_HOSTS.
Fontes antigas ainda aparecemRecarregue sem cache (Ctrl+Shift+R) ou rode docker compose up -d --build.
Várias instâncias do servidorDefina PRUMO_REDIS_URL para que todas compartilhem os eventos.
